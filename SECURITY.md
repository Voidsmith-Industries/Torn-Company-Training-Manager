# Security Policy

## Supported version

Security fixes are applied to the current release line.

## Reporting a vulnerability

Please do **not** open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting/security-advisory flow when available. If it is unavailable, contact the Voidsmith Industries maintainer through the organization contact address shown on the Voidsmith Industries GitHub profile.

Never include Torn API keys, RFC tokens, cookies, authentication/session data, personal data, or other secrets in issues, screenshots, logs, artifacts, or pull requests.

## Scope

Reports are useful when they concern training action guards, payroll controls, API handling, local data/audit storage, HTML rendering, update integrity, dependencies, build tooling, or repository automation. Torn.com itself is outside this repository's control.
